## Default Permission

Default permissions for Relix Android keepalive

#### This default permission set includes the following:

- `allow-start-keepalive`
- `allow-stop-keepalive`
- `allow-is-keepalive-running`
- `allow-get-notification-permission-status`
- `allow-request-notification-permission`
